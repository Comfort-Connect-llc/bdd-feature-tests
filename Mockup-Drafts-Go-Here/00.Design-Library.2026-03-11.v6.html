Usage Guidelines

Background Rules

  • ✓ DO: Use Color logos on white or light (--bg-general, --bg-primary) backgrounds
  • ✓ DO: Use White logos on navy (--cc-navy) or dark navy (--cc-navy-dark) backgrounds
  • ✓ DO: Use Black co-brand for single-color / monochrome print applications
  • ✗ DON'T: Place white logos on black (#000) backgrounds — use navy or dark navy instead
  • ✗ DON'T: Use color logos on dark or navy backgrounds — switch to white variant
  • ✗ DON'T: Separate the CC icon from the wordmark in the horizontal lockup

Minimum Clear Space

  • Maintain a clear zone equal to the height of the "C" in "Connect" on all sides
  • Co-brand lockup: maintain the divider line between CC and PremierProgram marks

Icons

The portal icon system uses Lucide Icons (a maintained fork of Feather Icons) as the primary icon library, supplemented by custom domain-specific icons for HVAC and financing workflows. Icons are rendered as inline SVGs at 24px default with 2px stroke width.

Sizing Scale

Icons follow a 4-step sizing scale. Use the smallest size that maintains clarity at the intended viewing distance.

16px — Inline / Badge
20px — Form / Small UI
24px — Default
32px — Feature / Hero
Stroke width2px (default), 1.5px for 16px icons
Line cap / joinRound
Optical alignmentCenter within bounding box
Touch targetMin 44×44px (icon + padding)

Implementation

Lucide icons are loaded via CDN and initialized with lucide.createIcons(). Use data-lucide attributes on any element to render icons.

CDN<script src="https://unpkg.com/lucide@latest"></script>
Init calllucide.createIcons() — called once after DOM load
HTML usage<i data-lucide="icon-name"></i>
SizingSet width / height via style or class
ColorInherited from color CSS property (uses currentColor)
Custom iconsUse inline <svg> with matching stroke conventions (2px, round caps)
AccessibilityAdd aria-label for interactive icons; aria-hidden="true" for decorative
